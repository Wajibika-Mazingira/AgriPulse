# Majajani Farms Banana Project

Pilot deployment of **AgriPulse FMIS** at Majajani Farms, focused on banana cultivation.

## Overview

This pilot adapts the AgriPulse edge cluster to a banana farming operation — monitoring soil, climate, and irrigation conditions to support data-driven agronomy on site, with no cloud dependency.

| Field      | Value                    |
|------------|--------------------------|
| Farm       | Majajani Farms           |

| Location   | _TBD_                    |
| Cluster    | 3-node Raspberry Pi 5    |
| AI         | Hailo-10H + Ollama       |

## Objectives

- Deploy the AgriPulse edge cluster on site.
- Instrument banana plots with soil and climate sensors.
- Provide real-time telemetry and on-device agronomy assistance.
- Validate the FMIS workflow under real farm conditions.
